Apple Pay domain verification
-----------------------------
Once SumUp has enabled Apple Pay for your account, add thegarrison.im under
SumUp Dashboard > Settings > For developers > Payment wallets. They give you a
domain verification file. Save it in this folder with EXACTLY this name (no extension):

    apple-developer-merchantid-domain-association

Then deploy and click "Verify" in the SumUp dashboard. Do not edit its contents.
Delete this README afterwards if you like (it is harmless).
